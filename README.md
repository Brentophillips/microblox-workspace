# MicroBlox - Experimental IATI Messaging Platform

Microblox is demonstration project

## What's IATI

IATI is an open data shairing framework. IT teams converta data into XML and publish files, then register file metadata to IATI'registry.

Reporting is driven by reporting comitments. There is longstanding interest in making file generation collaborative process and give staff visibility to file pipeline. For small teams, create more direct visibility and engagement. Also as emphasis shifts to AI search visibility, more interest in contents of information, checking connections, searchability.

## Messaging Exoskeleton

Messaging framework for publishers. Incorporate others into process or oversight

## MicroBlox XML Editor

Demonstration project: enable file generation to be more interactive and collaborative, presurve natural privacy steps, enable visibility.

Demostrate use of original messaging platfortm to send code snippets, establish a consensus mechanism, enable iterative process heading towards public reporting.

Use of AI in the process and new PubNub capabilities.

## XML Editor for AI Agents

We are curious if the framework can work for agents. What common prompts might a user ask an agent relative to file generation (has this been reported, start a file, solicide input, establish consensus, submit or que for review, publish XML, formally publish to IATI, update)

Can this stripped down editor be controled via MCP or etc?
